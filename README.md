# 🎓 Smart Campus Analytics Dashboard

A full-stack MERN application built for managing and analyzing student attendance data with authentication, analytics dashboards, charts, CRUD operations, and modern UI features.

---

# 🚀 Live Features

## 🔐 Authentication System
- JWT Authentication
- Login & Registration
- Protected Dashboard Access
- Token Storage using LocalStorage
- Logout Functionality

---

# 📊 Analytics Dashboard

## Dashboard Statistics
- Total Students

- Dynamic Analytics Cards

## Data Visualization
- 📈 Bar Charts
- 🥧 Pie Charts
- Attendance Analytics

# ⚙️ Installation & Setup

## 1️⃣ Clone Repository

```bash
git clone https://github.com/polamukesh/Smart-Campus-Analytics.git
```

---

## 2️⃣ Install Frontend Dependencies

```bash
cd client
npm install
```

---

## 3️⃣ Install Backend Dependencies

```bash
cd ../backend
npm install
```

---

# ▶️ Run Project

## Start Backend

```bash
cd backend
npx nodemon server.js
```

Backend runs on:

```bash
http://localhost:5000
```

---

## Start Frontend

```bash
cd client
npm run dev
```

Frontend runs on:

```bash
http://localhost:5173
```

---

# 🔑 Environment Variables

Create a `.env` file inside backend folder.

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
```
